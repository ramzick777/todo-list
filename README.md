# Мои задачи — To-Do List

Простой адаптивный веб-сайт для управления повседневными задачами.

## Возможности
- Добавление задач.
- Отметка задачи как выполненной и возврат в активные.
- Удаление отдельных задач.
- Фильтрация: все / активные / готовые.
- Удаление всех выполненных задач.
- Автоматическое сохранение в `localStorage` — список остаётся после обновления страницы в том же браузере.

## Запуск
1. Скачайте или клонируйте проект.
2. Откройте `index.html` в браузере.

Сборка, установка зависимостей и сервер не требуются.

## Структура
- `index.html` — разметка страницы.
- `style.css` — оформление и адаптивность.
- `script.js` — логика задач и сохранение данных.

## Использованные технологии
HTML5, CSS3, JavaScript (без сторонних библиотек), Web Storage API (`localStorage`).

## Публикация на GitHub Pages
1. Создайте публичный репозиторий на GitHub, например `todo-list`.
2. Загрузите в него три файла проекта и этот README.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
5. Сохраните настройки. Через некоторое время сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/todo-list/`.
